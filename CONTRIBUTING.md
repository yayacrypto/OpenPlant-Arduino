# Contributing to OpenPlant

Thanks for your interest in improving OpenPlant!

## Useful contributions

- Fixing bugs or improving reliability
- Adding calibration examples for a documented sensor model
- Improving wiring and safety documentation
- Testing on another supported Arduino-compatible board
- Improving accessibility or translating documentation

## Before opening a pull request

1. Explain the problem and the proposed change.
2. Keep changes focused and document any new settings.
3. Compile the sketch for the board you tested.
4. Include your board, sensor, and test setup where relevant.
5. Never claim hardware testing you have not performed.
6. Do not include secrets, personal information, or credentials.

For hardware-related changes, describe safe test conditions and any limitations. See the issue templates for bug reports and feature requests.
